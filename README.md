# About this Repo

This repository holds GenAI logs for work executed on the [Open Logic](https://github.com/open-logic/open-logic) project.

This is required for fulfill the [NLnet GenAI Policy](https://nlnet.nl/foundation/policies/generativeAI/).

Logs for work excuded using GenAI are stored in this repo and referenced from the commit message in the main repo.

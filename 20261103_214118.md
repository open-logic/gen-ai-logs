<command-args>Generate a new linear approximation entity, similar to what we do for olo_fix_inv and olo_fix_sqrt. The new entity shall be named "olo_fix_log2" and calculated the logorithm of two.

The idea is to approximate the log2() function in the range 1...2 using olo_fix_lin_approx (use the same output precisions as for inv/sqrt). The input is then normalized into this range (based on leading zero detection, same as we do it for olo_fix_inv). The leading zero detection produces the integer part of the output, the appoximation produced the fractional part of the output.

Of course the output is then rounded/saturated to the exact format the user requested.

constant IntBits_c : natural := max(log2ceil(max(InFmt_c.I, 0)), log2ceil(max(InFmt_c.F, 0)));

- **Look at existing diagrams first:** study the inv, sqrt and lin_approx figures before drawing. Read the embedded XML to reuse the exact styles.
- **Symbols instead of boxes:**
  - Blue boxes are not used for arithmetic or wiring.
  - Add, subtract and multiply are circles with `+`, `-` and `x`.
  - Constants are plain labels with an arrow into the circle.
  - Concatenation is a thick vertical bar.
  - A wiring-only step is shown as an operation, for example adding `-1` instead of a "Drop MSB" box.
  - Grey boxes are Open Logic entities, blue boxes are custom logic that has no symbol, and yellow boxes are tables.
- **Labels follow the code:** use the real names from the code, and check what a constant means before labelling it. The `IntBits-1` versus `I-1` case is the example. If your wording differs from the code, use the code-correct label and tell you.
- **Layout:** main data path on one horizontal line, side paths below it, orthogonal lines only, and no pipeline registers unless you ask for them.
- **Workflow:**
  - Generate the XML with a small Python script and iterate on the script, not the PNG.
  - Export with `drawio -x -f png --embed-diagram`, so the PNG carries its own source.
  - The snap `drawio` cannot read files in the scratchpad or `/tmp`, so the source file is copied next to the target first and deleted after.
  - Check the render with the Read tool, then add the image to the doc and lint it.

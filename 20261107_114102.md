`olo_fix_mov_avg` now handles multiple TDM channels. The Python model is unchanged and still models one channel. All 64 `olo_fix_mov_avg` simulations pass on GHDL (I only ran this entity's tests, not the full suite), lint is clean, and the model's 13 pytest tests pass. Nothing is committed yet.

**How it works** ([olo_fix_mov_avg.vhd](src/fix/vhdl/olo_fix_mov_avg.vhd))
- New generic `Channels_g` (default 1), a new input `In_Last` (default '0') and a new output `Out_Last`. Since the entity shipped in 4.6.0, I kept it backward compatible: existing instances work unchanged, with the same latency.
- The tap delay line is now `Taps_g * Channels_g` long.
- The moving sum feeds back through a new `olo_base_delay` of `Channels_g - 1`, which holds each channel's running sum. With one channel that delay has length 0 and is just a wire, so there is no separate code path for the single-channel case.
- `Out_Last` comes from a counter on the output valid, so it adds no latency. As in `olo_fix_cic_dec_tdm`, `In_Last` is only checked by a simulation assertion; the design assumes samples arrive strictly in channel order.

**Tests**
- [cosim.py](test/fix/olo_fix_mov_avg/cosim.py) runs the model once per channel, with a different amplitude per channel, and writes interleaved `In.fix`/`Out.fix`.
- The testbench uses TDM stimuli/checker mode, so `Out_Last` is checked too.
- New configs in [olo_fix.py](sim/test_configs/olo_fix.py): 2 and 3 channels with each gain correction type, `Taps_g=1`, no output registers, and 7 channels with 5 taps. They have short names because VUnit's auto-generated names made file paths too long.
- I checked that the tests catch errors: with the per-channel sum delay deliberately set wrong, every multi-channel config failed.

**Docs and config**
- [olo_fix_mov_avg.md](doc/fix/olo_fix_mov_avg.md) has a TDM description, the new generic and ports, and a section on how the architecture changes.
- [EntityList.md](doc/EntityList.md) is updated, and there is a new 4-channel inference config in `tools/inference_test/yaml/fix.yml`.
